Getting Started

bash
# Clone the repository
git clone https://github.com/wends155/plantlink.git
cd plantlink

# Run the full stack (UI + Backend) in development mode
make run

# Build a single optimized release binary
make build-release

Prerequisites

  • Rust: Stable toolchain installed (latest)
  • Node.js: v20+ (for UI build)
  • Make: GNU Make
